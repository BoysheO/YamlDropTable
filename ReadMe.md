# YamlDropTable设计

## 概念
| 名字    | 说明                                                          |
| ----- | ----------------------------------------------------------- |
| 掉落 id | 代表一个道具 id 或另一个掉落池 id。`0` 固定表示空掉落。                           |
| 掉落数量  | 代表一次掉落的数量。既可以表达为固定数量，也可以表达为范围值。为了便于配置，数量为 `0`时，视作数量1处理。负数表示本次为空掉落。 |
| 权重    | 代表一个掉落 id 被抽中的权重，用整数表示。允许权重为 `0`，权重为 `0` 表示该项不会被抽中。权重不能为负数。 |
| 掉落池   | 代表一组掉落项。抽奖一次，掉落池只能从自身掉落项中抽出其中一个结果。                          |
| 掉落表   | 代表一组掉落池。抽奖一次，掉落表中的所有掉落池各自抽出一个结果。                            |
## 掉落 id 格式
掉落 id 有两种格式：
```text
<掉落类型><id>
```
或：
```text
0
```
其中，掉落类型使用单个小写字母表达。
| 字母  | 语义  |
| --- | --- |
| `i` | 道具  |
| `t` | 掉落池 |

id可以是中文，例如 `开服活动掉落表`。
道具一般使用道具数字id来作为id。
## 掉落数量格式
掉落数量使用 `count_` 字段表达。
固定数量：
```yaml
count_: 1
```
范围数量：
```yaml
count_: [2, 4]
```
数量为负数时，表示空掉落
```yaml
- weight: 20
  drop__: i1001
  count_: -1
```
也可以直接使用 `drop__: 0` 表示空掉落：
```yaml
- weight: 20
  drop__: 0
```
缺省时，视作数量1
(yaml解析器可能会解析为0、null，都视作0；然后因为`0视作1`的规则，数量处理上认为是1而不是0)
```yaml
- weight: 20
  drop__: i223
  #这里少了count值
```
## 权重规则
权重使用 `weight` 字段表达。
```yaml
weight: 100
```
规则如下：

| 规则                 | 说明           |
| ------------------ | ------------ |
| 权重必须是整数            | 不允许小数        |
| 权重不能为负数            | 例如 `-1` 非法   |
| 权重可以为 `0`          | 表示该项不会被抽中    |
| 权重为 `0` 的项可以保留在配置中 | 常用于临时关闭某个掉落项 |

注意区分：

| 配置          | 含义                        |
| ----------- | ------------------------- |
| `weight: 0` | 没有概率发生                    |
| `drop__: -1` | 有概率发生，发生后为空掉落             |
| `count_: 0` | 有概率发生，发生后为空掉落 |

## 掉落池表达格式
掉落池使用 YAML 中的键值结构表达。
一个掉落池由多个掉落项组成。每个掉落项包含：
| 字段       | 必填 | 说明           |
| -------- | -- | ------------ |
| `weight` | 是  | 权重           |
| `drop__` | 是  | 掉落 id        |
| `count_` | 否  | 掉落数量，缺省为 `1` |

示例：
```yaml
装备池:
  - weight: 100
    drop__: i1001
    count_: 1
  - weight: 50
    drop__: i1002
    count_: [2, 4]
  - weight: 20
    drop__: 0
```
该掉落池抽奖一次时，只会从上述掉落项中抽出一个结果。
## 掉落表表达格式
掉落表使用 YAML 格式表达，根节点为 `groups`。
`groups` 下的每一个键代表一个掉落池名。掉落池名仅用于当前掉落表内识别不同掉落池，不是掉落池 id。
示例：

```yaml
groups:
  装备池:
    - weight: 100
      drop__: i1001
      count_: 1
    - weight: 50
      drop__: i1002
      count_: [2, 4]
    - weight: 20
      drop__: 0
  材料与消耗品池:
    - weight: 80
      drop__: i2001
      count_: 1
    - weight: 40
      drop__: i2002
      count_: [1, 3]
    - weight: 10
      drop__: t3001
      count_: 1
    - weight: 70
      drop__: 0
  货币池:
    - weight: 100
      drop__: i3001
      count_: 5
    - weight: 30
      drop__: i3002
      count_: 1
    - weight: 0
      drop__: i3999
      count_: 1
```
抽奖一次时：
1. `装备池` 抽出一个结果；
2. `材料与消耗品池` 抽出一个结果；
3. `货币池` 抽出一个结果。
因此，该掉落表一次结算会执行所有掉落池。每个掉落池最多产生一个结果。如果某个掉落池抽中 `drop__: 0`，则该组本次为空掉落。
## 掉落池命名规则
掉落表中的掉落池名可以使用中文，也可以使用英文。

```text
中英文开头，中英文、数字、下划线组合
```
示例：

```yaml
groups:
  装备池:
    - weight: 100
      drop__: i1001
  material_pool:
    - weight: 100
      drop__: i2001
  g01_currency:
    - weight: 100
      drop__: i3001
```
## 单独的掉落池定义
如果要使用 `t` 类型的掉落 id，例如：
```yaml
drop__: t极品装备池
```
则必须在其他配置位置单独定义掉落池 `极品装备池`。
该定义应放在独立 YAML 文件中，以yaml文件名作为id，或其他配置系统中配置。
示例：
```yaml
#文件名 极品装备池.yaml
#固定格式，使用groups开头。
groups:
#掉落池必须有一个命名作为开始，这里的掉落池命名`装备池`和id没有关系，但推荐命名为和文件名一致，以便于同时打开多个yaml文件时，能从内容上区分它们是不同的文件。
  装备池:
    - weight: 100
      drop__: i5001
      count_: 1
    - weight: 50
      drop__: i5002
      count_: [1, 3]
    - weight: 20
      drop__: 0
```
当主掉落表抽中 `t极品装备池` 时，会继续结算掉落池 `极品装备池`。
## 配置示例
```yaml
# 掉落表开始
groups:
  # 装备池。掉落池名可以为中文、英文、数字、下划线组合。
  装备池:
    # 权重。可以为 0，表示该项不会被抽中。
    - weight: 100
      # 掉落 id。
      drop__: i1001
      # 掉落数量。缺省值为 1。
      count_: 1
    - weight: 50
      drop__: i1002
      count_: [2, 4]
    # 空掉落。该项被抽中后，本组不产出道具。
    - weight: 20
      drop__: 0
  # 材料与消耗品池。
  材料与消耗品池:
    - weight: 80
      drop__: i2001
      count_: 1
    - weight: 40
      drop__: i2002
      count_: [1, 3]
    # 引用掉落池 t3001。
    - weight: 10
      drop__: t3001
      count_: 1
    - weight: 70
      drop__: 0
  # 货币池。
  货币池:
    - weight: 100
      drop__: i3001
      count_: 5
    - weight: 30
      drop__: i3002
      count_: 1
    # 权重为 0，表示该项不会被抽中。
    - weight: 0
      drop__: i3999
      count_: 1
  
  #引用极品装备池
  装备池2:
    - weight: 1
      drop__: t极品装备池
      count_: 1
```
## 设计原则
使用 YAML 格式设计掉落表。
